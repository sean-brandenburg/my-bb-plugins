# Thread header project

Puts the project name in a thread's header, so the composer footer doesn't need to carry it.

## What you get

- **The project in front of the title**: the header reads `my-bb-plugins › Thread title`, in the title's size and a muted color. Personal threads show no project.
- **A shorter footer**: bb's project and environment labels under the composer are hidden; the footer's branch already says which environment.

Phone widths keep bb's stock header and footer, so the project stays in the footer there.

Split panes each get their own project label. Disabling the plugin restores bb's normal header and footer labels.
